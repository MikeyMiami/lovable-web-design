# Master SEO timeline (expert-grounded) — what to build/publish/adjust, when

> The authoritative phased timeline for a client's SEO program, grounded in the transcripts (`ZKZnDORR0ds` = the a-to-z system + rank map; `FifSqbB0` = the content/research tool). Cited `<ID>:line`. Also the spec basis for the Slice-5 one-click flows (which map 1:1 to these phases). **No build — reference + review.**

## The load-bearing principle [LOCKED]
Two relevance layers, built in ORDER, gated by the rank map: **topical first (Core-30 + supporting), then geographic (geo), never the reverse.** *"Most agencies start building location pages… before they've proven topical authority. And those location pages do nothing because Google just doesn't trust them yet"* (`ZKZnDORR0ds:294-295`). *"monitor your rank map. Check your top 3%. Decide what type of content to build next. This is a system"* (`:395`).

---

## PHASE 0 — First creation (Day 0, launch)
**Build the entire Core-30 topical foundation and publish it. No geo. No supporting.**
- **(1) BUILT:** the full **Core-30** — home (primary category + city) → category pages (secondary categories) → service pages — mirroring the GBP. *"one homepage, three to four category pages, and 25-30 service pages… these 30 pages create the **foundation** of topical relevance Google needs to see before it will rank you"* (`ZKZnDORR0ds:173-176`).
- **(2) DEEP-WRITTEN:** every Core-30 page (research → the writing pipeline). Built with AI but made "look like a real website" (`ZKZnDORR0ds:202-214`); the tool's Core-30 agent does setup→brief→research→writing→schema→images→publishing (`FifSqbB0:113-127, 315-318`, `W3deWbeigsg:157-160`).
- **(3) PUBLISHED:** **all Core-30 pages, at launch — NOT staged in waves.** The Core-30 IS the foundation ("when you're done with the core 30, you have 30 pages of content… this is what topical relevance looks like", `ZKZnDORR0ds:211-214`); it goes live together as the topical base. (Waves/gating apply to *geo*, not the Core-30.)
- **Authority link — YES, at Day 0:** one authority ("not-AI-slop") external link **per Core-30 page** — *"for your 30 core 30 pages, that's 30 external links"* (`ZKZnDORR0ds:228-232`).
- **Geo at Day 0 — NO.** Built only after topical authority is proven (see Day 30) (`ZKZnDORR0ds:294-295, 352-355`).
- **Supporting at Day 0 — NO.** Triggered by the 30-day rank check when below threshold (`ZKZnDORR0ds:263, 300-352`).
- **(4) SIGNAL:** none yet — Day 0 is unconditional (build the foundation).
- **(5) HUMAN vs AUTO:** automated build/deep-write; **human gates** = photo placement + the authority links (operator-supplied). *(= Slice-5 FLOW 1.)*
- **State at launch:** Core-30 live (home + categories + services), each with one authority link. Nothing else.

## FIRST 30-DAY CHECK (Day ~30) — measure, then topical OR geo
**Wait ~30 days, then measure — don't expand blind.** *"30 days after you've launched the core 30, it's time to start running more rank maps for your target keyword"* (`ZKZnDORR0ds:263-265`).
- **Measure:** run a rank map for the target keyword → **top-3%** (% of the 169-point grid at positions 1-3) → compare to competitors' top-3% → **threshold = 25-50% of the leaders' top-3%** (leaders at 80% → threshold 30-40; at 40% → 15-20) (`ZKZnDORR0ds:266-290`).
- **Decision by signal** (`ZKZnDORR0ds:287-299, 401-402`):
  - **BELOW threshold → SUPPORTING content (topical).** Build highly-targeted supporting pages answering the specific questions the rank map shows you're weak on; add a brief FAQ + editorial link on the relevant **core** page → deep supporting page; each supporting page needs one authority link. *"keep building these supporting content until you hit your top 3% threshold"* (`ZKZnDORR0ds:300-352`). **Quantity: ~10-20 supporting pages** (`:348-349`).
  - **AT/ABOVE threshold → GEO (first wave).** Google now trusts you're an authority → expand geographically. **Build 10-20 geo pages** targeting landmarks/neighborhoods where you're at grid **positions 4-6**, published **in waves** (`ZKZnDORR0ds:352-395`; *"build 10 to 20 of these geographical pages"* `:383-384`).
  - **DOMINATING → maintain** (rare this early).
- **(1-3) BUILT/WRITTEN/PUBLISHED:** the chosen batch (supporting *or* geo), deep-written, and **published as a wave (~10-20)** — never blanket-launch geo (`ZKZnDORR0ds:294-295`).
- **(4) SIGNAL:** the top-3%-vs-threshold read (fed as the 3-state `topical_status`).
- **(5) HUMAN vs AUTO:** **human** = run the manual rank map + set the signal; **automated** = build/deep-write/publish the batch.

## SECOND 30-DAY CHECK (Day ~60) — next wave, keep alternating
- **Re-measure:** rank map again. *"keep running that rank map **every couple of weeks**"* for geo, monthly overall (`ZKZnDORR0ds:387-388, 401`).
- **Decision:**
  - Still **below** → more **supporting** (keep earning topical authority until threshold, `:350-353`).
  - **At/above** → **next GEO wave** — target the **new areas now showing positions 4-6** (as authority builds you appear in more places): *"Look for new areas where you're now in positions four through six… Target the new areas. Keep expanding outward"* (`ZKZnDORR0ds:387-391`). Another 10-20, each internally linked to its service page + the locations index + one authority link (`:381-388`).
- **(1-3):** the next batch built/deep-written/**published in a wave**.
- **Alternation begins:** *"Alternate between topical content when needed and geographical content when you're above threshold"* (`ZKZnDORR0ds:393-395`).

## EACH SUBSEQUENT 30-DAY CHECK (Day 90, 120, …) — the ongoing rhythm
**The repeating monthly system:** *"Every month, run your rank map. Check your top three metric. Look at where you're still weak. Are you below threshold? More topical content. At threshold, build geographical content. Dominating everywhere? Maintain and defend"* (`ZKZnDORR0ds:401-402`).
- **Cycle:** check rank → per signal build/deep-write/publish the next wave (supporting if below, geo if at/above) → repeat. Geo re-checked ~every 2 weeks, overall monthly.
- **Cadence/volume:** a monthly batch (~10-20 pages; retainer floor ≈ **12 articles/mo** per `seo-content §8`). The green zone grows outward from the address over time (`ZKZnDORR0ds:389-395`).
- **Alternate topical ↔ geographic** by the signal until *"you're dominating your entire service area"* (`:393-395`).
- **STOP / MAINTAIN (dominating everywhere):** *"Maintain and defend. Keep your GBP active… add new services as the business evolves, watch competitors, consider a second location/GBP"* (`ZKZnDORR0ds:401-406`). **Maintain = stop the wave machine; keep the GBP active, add pages only as the business adds real services, watch competitors — not blanket-publishing.**

## Slice-5 automation mapping (the three flows = these phases)
- **FLOW 1 "Build All Core Pages"** = Phase 0 (Core-30 → research → deep-write → images → authority links → publish, human gates at photos + links).
- **FLOW 2 "Build Geo Pages"** = the *established* branch of each 30-day check (seed geo for close_towns → deep-write → wave-publish).
- **FLOW 3 "Build Supporting Pages"** = the *building* branch (add supporting for weak core pages → deep-write → FAQ+link → publish).
- The **cadence board + `topical_status` + `close_towns`** are the manual signal each flow reads. `publishGeoWave` enforces the wave discipline; `deleteGeoPages`/reset enable rebuilds.

## The minimum operator input each cycle [from B5]
Per 30-day check, the operator feeds just: **`topical_status`** (building | established | dominating) + (when established) the **`close_towns`** showing grid positions 4-6. Everything else (which questions, which landmarks, the writing) the research + hardened deep-writer produce.

---
**Net:** Day 0 = build+publish the whole Core-30 (topical foundation) + one authority link/page; **no geo, no supporting**. Every ~30 days: rank map → below = supporting wave, at/above = geo wave (10-20, positions 4-6), dominating = maintain — alternating topical↔geographic until you dominate the service area. Tooling already implements every step; Slice-5 collapses each phase into one button.
